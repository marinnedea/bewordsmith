# Setup & Installation

Goal: get the site running locally. You only need Python 3 — no packages to install.

## Run it

```bash
cd wiki-template
python3 server.py            # serves on http://localhost:8000
python3 server.py 8137       # …or pick a port
```

Then open the printed URL. The server binds to `127.0.0.1` only (local-only).

## Make it yours

Open `server.py` and edit the config block at the top:

```python
SITE_TITLE    = "BeWordsmith"       # sidebar brand + browser tab
SITE_SUBTITLE = "Docs & guides"     # small line under the brand
CONTENT_DIR   = "content"           # where your .md files live
PAGE_WORD     = "page"              # noun for the menu counts
```

To re-skin the whole site, change one CSS variable — `--accent` — near the top of the shell styles.
