# Setup & Installation

Goal: get the site running locally. You only need Python 3 — no packages to install.

## Run it

```bash
cd wiki-template
python3 server.py            # serves on http://localhost:8000
python3 server.py 8137       # …or pick a port
```

Then open the printed URL. The server binds to `127.0.0.1` only (local-only).

## Make it yours

Everything lives in `config.json` next to `server.py`:

```json
{
  "site_title": "BeWordSmith",
  "site_subtitle": "Docs & guides",
  "content_dir": "content",
  "page_word": "page",
  "port": 8000
}
```

A port passed on the command line (`python3 server.py 8137`) overrides the one in `config.json`. To re-skin the whole site, change one CSS variable — `--accent` — near the top of the shell styles in `server.py`.
