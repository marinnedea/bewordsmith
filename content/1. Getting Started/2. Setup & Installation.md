# Setup & Installation

Goal: get the site running. Pick whichever backend fits where you're hosting — both render the identical UI from the same content.

## Option A — Python (local dev)

No packages to install; just Python 3.

```bash
python3 server.py            # serves on http://localhost:8000
python3 server.py 8137       # …or pick a port
```

The server binds to `127.0.0.1` by default (set `host` to `0.0.0.0` for LAN/containers).

## Option B — PHP (Apache / nginx / shared hosting)

Most shared and cPanel hosts give you PHP by default and don't allow a long-running process. For those, use `index.php`:

```bash
php -S localhost:8000 index.php   # local test
```

To deploy on shared hosting, **upload the whole folder** — `index.php` is the entry point and the included `.htaccess` handles the rest. URLs are relative, so it works in any subdirectory with no configuration.

## Make it yours

Everything lives in `config.json` (read by both backends):

```json
{
  "site_title": "BeWordSmith",
  "site_subtitle": "Docs & guides",
  "content_dir": "content",
  "page_word": "page",
  "host": "127.0.0.1",
  "port": 8000,
  "base_path": "",
  "accent": "#FF671D",
  "home": ""
}
```

See **Reference → Configuration** for every key, theming, and nginx/Apache examples.
